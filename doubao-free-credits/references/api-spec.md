# 方舟余额查询接口说明

## 接口

```
GET https://ark.cn-beijing.volces.com/api/v3/users/me
Authorization: Bearer <ARK_API_KEY>
```

官方公开的用户信息查询接口，用于验证 Key 有效性并返回账户身份信息。**只读**，不消耗 token。

## 凭据

- 环境变量 `ARK_API_KEY`，或命令行 `--key`
- 凭据也支持落盘：`~/.workbuddy/doubao-ark-key.json`（`{"api_key": "..."}`），权限尽量设为仅本人可读
- 脚本在任何输出中**只显示 Key 的前 4 位与后 4 位**，绝不打印完整 Key

## 响应关键字段

| 字段 | 含义 |
|---|---|
| `id` | 账户 ID |
| `name` / `email` | 账户标识 |
| `ark_api_key` 相关字段 | 当前 Key 的状态 |

免费额度剩余量以控制台「资源管理」页面为准；接口本身不直接返回赠送额度余额。脚本在拿到账户信息后会明确提示这一限制，并给出控制台查看路径。

## 常见错误

| HTTP | 原因 | 处理 |
|---|---|---|
| 401 | Key 无效或已过期 | 提示到方舟控制台重新创建 Key |
| 403 | 权限不足 / 未完成实名 | 提示完成实名认证 |
| 连接超时 | 网络问题 | 提示检查网络或改用国内直连环境 |

## 安全承诺

脚本不做任何写操作，不调用生成接口，不会消耗任何额度；除读取环境变量与可选的本地凭据文件外，不写任何文件。
